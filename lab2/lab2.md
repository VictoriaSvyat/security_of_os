## Задание 2.1

### Условие

Разработать сценарий, который ведёт журнал запусков в файле `/tmp/run.log`:

- в конец журнала добавляет строку с датой и временем запуска сценария
  (используйте команду date для фиксации даты и времени запуска
  сценария);
- в стандартный вывод (stdout) - выводит фразу "Hello, World!";
- в стандартный вывод ошибок (stderr) - выводит количество предыдущих
  запусков программы.

### Скрипт

```bash
#!/bin/bash

wc -l < /tmp/run.log >&2
date >> /tmp/run.log
echo "Hello, World!"
```

### Комментарии

```bash
wc -l < /tmp/run.log >&2
```

- `wc -l` — считает количество строк;
- `< /tmp/run.log` — передаёт содержимое журнала на стандартный ввод команды `wc`;
- `>&2` — перенаправляет результат в поток ошибок `stderr`.

Так как каждый запуск добавляет в журнал одну строку, число строк соответствует количеству **предыдущих запусков**.

```bash
date >> /tmp/run.log
```

- `date` — выводит текущую дату и время;
- `>>` — добавляет результат в конец файла, не удаляя старые записи.

```bash
echo "Hello, World!"
```

Команда выводит фразу `Hello, World!` в стандартный поток `stdout`.

## Задание 2.3

### Условие

Считать стандартный ввод и вывести в `stderr` только те строки, которые содержат слово `bin` целиком.

### Вариант 1 — обработка строк сразу

```bash

while read line
do
    echo "$line" | grep -w "bin" >&2
done
```

### Комментарии

```bash
while read line
```

```bash
grep -w "bin"
```

- `grep` выполняет поиск;

```bash
>&2
```

## Задание 2.4

### Условие

Для всех файлов с расширением `.txt` в домашнем каталоге:

- вывести список файлов;
- вывести суммарный размер в байтах;
- вывести суммарное количество строк.

### Скрипт

```bash
#!/bin/bash

files=("$HOME"/*.txt)

if [ ! -e "${files[0]}" ]
then
    echo "Файлы .txt не найдены"
    exit 0
fi

printf "%s\n" "${files[@]}"

echo "Найденные файлы:"
printf "%s\n" "${files[@]}"

echo "Суммарный размер (байты):"
wc -c "${files[@]}"

echo "Суммарное количество строк:"
wc -l "${files[@]}"
```

### Комментарии

```bash
files=("$HOME"/*.txt)
```

Сохраняет список `.txt`- файлов домашнего каталога в массив `files`.

```bash
if [ ! -e "${files[0]}" ]
```

`${...}` - форма обращения к переменной

`"..."` - нужны, чтобы имя файла с пробелами воспринималось как одно значение.

Проверяет, был ли найден хотя бы один файл.

```bash
printf "%s\n" "${files[@]}"
```

Выводит список найденных файлов.

```bash
wc -c "${files[@]}"
```

`@` - все элементы массива

Считает размер файлов в **байтах**. При нескольких файлах `wc` выводит строку `total` с общей суммой.

```bash
wc -l "${files[@]}"
```

Считает количество строк. Строка `total` содержит суммарное количество строк во всех файлах.

## Задание 2.5

### Условие

Найти файлы с одинаковым содержимым и вывести для каждого такого файла количество его дубликатов и имя файла. Файлы без дубликатов не выводить.

### Скрипт

```bash
#!/bin/bash

for file in *
do
    if [ ! -f "$file" ]
    then
        continue
    fi

    count=0

    for other in *
    do
        
        if [ -f "$other" ]
        then 
            continue
        fi

        
        if [ "$file" = "$other" ]
        then
            continue
        fi

        if cmp -s "$file" "$other"
        then
            count=$((count + 1))
        fi
    done

    if [ "$count" -gt 0 ]
    then
        echo "$count $file"
    fi
done
```

### Комментарии

```bash
for file in *
```

Перебирает все объекты текущего каталога.

```bash
if [ ! -f "$file" ]
    then
        continue
    fi
```

Оставляет только обычные файлы. Каталоги и другие объекты пропускаются.

```bash
count=0
```

Счётчик найденных дубликатов текущего файла.

```bash
if [ "$file" = "$other" ]
then
    continue
fi
```

Не позволяет сравнивать файл с самим собой.

```bash
cmp -s "$file" "$other"
```

Сравнивает содержимое двух файлов. Опция `-s` включает тихий режим: `cmp` не печатает результат сравнения, а только возвращает код завершения.

```bash
count=$((count + 1))
```

Увеличивает количество найденных дубликатов.

```bash
if [ "$count" -gt 0 ]
```

Файл выводится только в том случае, если у него найден хотя бы один дубликат.

## Задание 2.7

### Условие

Написать скрипт `filter_numbers.sh`, который:

- принимает список чисел через `$@`;
- пропускает числа, делящиеся на `3`;
- чётные числа записывает в `even.txt`;
- нечётные числа записывает в `odd.txt`;
- выводит количество обработанных чисел.

### Скрипт

```bash
#!/bin/bash

count=0

for number in "$@"
do
    if (( number % 3 == 0 ))
    then
        continue
    fi

    if (( number % 2 == 0 ))
    then
        echo "$number" >> even.txt
    else
        echo "$number" >> odd.txt
    fi

    count=$((count + 1))
done

echo "Обработано чисел: $count"
```

### Комментарии

```bash
for number in "$@"
```

`"$@"` содержит все аргументы, переданные сценарию.

```bash
if (( number % 3 == 0 ))
```

`(( ... ))` - предназначены для **арифметики**

Проверяет делимость числа на `3`.

```bash
continue
```

Пропускает текущую итерацию цикла и переходит к следующему числу.

```bash
if (( number % 2 == 0 ))
```

Проверяет чётность числа.

```bash
echo "$number" >> even.txt
```

Добавляет чётное число в файл `even.txt`.

```bash
echo "$number" >> odd.txt
```

Добавляет нечётное число в файл `odd.txt`.

```bash
count=$((count + 1))
```

Увеличивает счётчик обработанных чисел.

> При повторном тестировании старые данные можно удалить командами `> even.txt` и `> odd.txt`.

## Задание 2.8

### Условие

Изучить обработку опций с помощью `getopts` и написать скрипт `smart_calc.sh`.

### Используемые опции

| Опция       | Назначение                |
| ----------- | ------------------------- |
| `-h`        | вывести справку           |
| `-v`        | включить подробный вывод  |
| `-o <file>` | записать результат в файл |
| `-a`        | сложение                  |
| `-m`        | умножение                 |
| `-s`        | вычитание                 |
| `-p`        | возведение в степень      |
| `-d`        | деление                   |

### Скрипт

```bash
#!/bin/bash

operation=""
verbose=0
output=""

while getopts "hamspdvo:" opt
do
    case "$opt" in
        h)
            echo "Использование: $0 [-a|-m|-s|-p|-d] [-v] [-o файл] числа"
            exit 0
            ;;
        a) operation="add" ;;
        m) operation="mul" ;;
        s) operation="sub" ;;
        p) operation="pow" ;;
        d) operation="div" ;;
        v) verbose=1 ;;
        o) output="$OPTARG" ;;
    esac
done

shift $((OPTIND - 1))

a=$1
b=$2

case "$operation" in
    add) result=$((a + b)) ;;
    mul) result=$((a * b)) ;;
    sub) result=$((a - b)) ;;
    pow) result=$((a ** b)) ;;
    div) 
        if [ "$b" -eq 0 ]
        then
            echo "Ошибка: деление на ноль невозможно"
            exit 1
        fi
    
        result=$((a / b))
        ;;
esac

if [ "$verbose" -eq 1 ]
then
    echo "Первое число: $a"
    echo "Второе число: $b"
    echo "Операция: $operation"
    echo "Результат: $result"
fi

if [ -n "$output" ]
then
    echo "$result" > "$output"
else
    echo "$result"
fi
```

### Комментарии

```bash
while getopts "hamspdvo:" opt
```

`getopts` разбирает переданные опции. Двоеточие после `o` означает, что опция `-o` требует аргумент - имя файла.

`;;` - конец ветки `case`

```bash
$OPTARG
```

Содержит аргумент текущей опции.

```bash
shift $((OPTIND - 1))
```

Удаляет из списка уже обработанные опции. После этого в `$1` и `$2` остаются числа.

```bash
case "$operation" in
```

Выбирает необходимую математическую операцию.

## Задание 2.9

### Условие

Подготовить CSV-файл с данными о продажах и написать `analyze_sales.sh`, который выводит:

1. общую сумму продаж;
2. среднюю стоимость продажи;
3. самую дорогую продажу.

Результат необходимо сохранить в `sales_report.txt` с помощью `tee`.

### Тестовый файл `sales.csv`

```csv
product,price
Book,500
Mouse,1200
Keyboard,2500
Monitor,18000
```

### Скрипт

```bash
#!/bin/bash

file=$1

awk -F, 'NR>1 {
    sum += $2
    count++
    if ($2 > max) max=$2
}
END {
    print "Общая сумма продаж:", sum
    print "Средняя стоимость:", sum/count
    print "Самая дорогая продажа:", max
}' "$file" | tee sales_report.txt
```

### Комментарии

```bash
file=$1
```

Сохраняет имя CSV-файла, переданного первым аргументом.

```bash
awk -F,
```

Запускает `awk` и задаёт запятую как разделитель полей.

Передаем в одинарных кавычках программе `awk`, надо для `$2` - второй столбец строки, а не второй аргумент Bash - скрипта.

```awk
NR > 1
```

Обрабатывать все строки, кроме первой (первая строка CSV - заголовок).

```awk
sum += $2
```

`$2` — второй столбец, то есть цена.

Добавляет значение второго столбца к общей сумме.

```awk
count++
```

Увеличивает количество обработанных продаж.

```awk
if ($2 > max) max=$2
```

Выясняет текущая цена больше максимальной найденной?

Сохраняет максимальную стоимость продажи.

```bash
END { }
```

Блок `END` выполняется **один раз после того, как `awk` прочитал весь файл**.

```bash
tee sales_report.txt
```

Одновременно 

- выводит результат на экран;
- записывает его в файл `sales_report.txt`.

## Задание 2.10

### Условие

Модифицировать скрипт из задания 2.9:

- по опции `-f csv` сохранять отчёт в CSV;
- по опции `-g` генерировать SQL-запросы для импорта `sales_report.csv` в PostgreSQL.

### Скрипт

```bash
#!/bin/bash

format=""
generate_sql=0

while getopts "f:g" opt
do
    case "$opt" in
        f) format="$OPTARG" ;;
        g) generate_sql=1 ;;
    esac
done

shift $((OPTIND - 1))

file=$1

sum=$(awk -F, 'NR>1 {sum += $2} END {print sum}' "$file")
avg=$(awk -F, 'NR>1 {sum += $2; count++} END {print sum/count}' "$file")
max=$(awk -F, 'NR>1 {if ($2 > max) max=$2} END {print max}' "$file")

if [ "$format" = "csv" ]
then
    echo "metric,value" > sales_report.csv
    echo "total,$sum" >> sales_report.csv
    echo "average,$avg" >> sales_report.csv
    echo "maximum,$max" >> sales_report.csv

    cat sales_report.csv
else
    {
        echo "Общая сумма продаж: $sum"
        echo "Средняя стоимость: $avg"
        echo "Самая дорогая продажа: $max"
    } | tee sales_report.txt
fi

if [ "$generate_sql" -eq 1 ]
then
    cat > import.sql <<EOF_SQL
CREATE TABLE sales_report (
    metric TEXT,
    value NUMERIC
);

COPY sales_report(metric, value)
FROM 'sales_report.csv'
DELIMITER ','
CSV HEADER;
EOF_SQL

    cat import.sql
fi
```

### Комментарии

```bash
while getopts "f:g" opt
```

Обрабатывает опции `-f` и `-g`.

```bash
f) format="$OPTARG" ;;
```

Сохраняет формат, переданный после `-f`.

Пример:

```bash
./analyze_sales.sh -f csv sales.csv
```

Создаёт файл:

```csv
metric,value
total,22200
average,5550
maximum,18000
```

Опция `-g` включает генерацию SQL.

Для создания файла `import.sql` используется here-document:

```bash
cat > import.sql <<EOF_SQL
...
EOF_SQL
```

В результате формируются SQL-команды:

```sql
CREATE TABLE sales_report (
    metric TEXT,
    value NUMERIC
);

COPY sales_report(metric, value)
FROM 'sales_report.csv'
DELIMITER ','
CSV HEADER;
```

Пример совместного запуска:

```bash
./analyze_sales.sh -f csv -g sales.csv
```
